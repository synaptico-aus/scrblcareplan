name: Model trials
description: Scope of model upgrades and quality comparisons for this care-planning app.
---

Preserve the existing prompts and guardrails when trialling replacement models unless the user asks to change them.

**Why:** The user emphasised that the app already has guardrails and prompts to stay within reason, and requested a smarter model rather than looser restrictions.

**How to apply:** Treat a model trial as a model-selection change; do not combine it with prompt or guardrail revisions.
